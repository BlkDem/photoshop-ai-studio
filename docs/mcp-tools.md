# MCP tools

> Generated by `node scripts/generate-tool-docs.mjs` from
> `shared/src/photoshop/operations.ts`. Do not edit by hand — that registry is the
> single source of truth for the MCP server, the planner prompt, the Studio Tools
> panel and the safety flags.

**Endpoint** `POST http://127.0.0.1:${MCP_PORT}/mcp` — Streamable HTTP, stateless.
**Naming** every tool is `photoshop.<operation>`. Dots are explicitly allowed by the
MCP tools specification.

## Conventions

These hold for all 30 tools:

- **Coordinates** are absolute document pixels. Origin is the canvas top-left, y grows
  downward.
- **Layer addressing** takes exactly one of `layerId` (preferred — stable across
  reordering) or `layerName` (convenient; an ambiguous name is an error, never a guess).
- **`documentId`** defaults to `"active"` — the document the user is looking at.
- **Paths** must resolve inside `WORKSPACE_ROOT`; anything else is `PATH_NOT_ALLOWED`.
- **Results** are `{ success: true, data }` or `{ success: false, error }`, and the
  payload is validated against the tool’s declared result schema on both sides.

### Result shape

```json
{ "success": true, "data": { "id": 3, "name": "Title", "type": "text" } }
```

```json
{
  "success": false,
  "error": {
    "code": "LAYER_NOT_FOUND",
    "message": "Layer \"Logo\" was not found",
    "recoverable": true,
    "details": { "available": ["Title", "Subtitle"] }
  }
}
```

`recoverable` is the field the repair loop reads. `true` means re-planning may
plausibly succeed; `false` means stop and tell the user.

### Expectations

Every mutating tool has post-conditions derived from its arguments — see
[architecture.md ADR-007](architecture.md#adr-007--expectations-are-derived-not-trusted).
A plan may add its own expectations; it cannot remove a derived one. Read-only tools
have none, and a plan with no checkable operations reports "no checks" rather than
claiming success.

| Expectation kind | Checks |
| --- | --- |
| `layer_exists` / `layer_absent` | a layer matching the selector exists / does not |
| `layer_property` | `name`, `visible`, `opacity`, `x`, `y`, `width`, `height`, `parentId`, `type`, `blendMode`, `isLocked` |
| `layer_parent_named` | the layer's parent group has the given name (used when the group is addressed by name, so the new `parentId` is only knowable afterwards) |
| `document_property` | `name`, `width`, `height`, `resolution`, `colorMode`, `layerCount`, `path`, `saved` |
| `text_property` | `text`, `font`, `fontSize`, `color` — read back through `photoshop.get_text_layer` |
| `layer_count` | the document has exactly N layers |
| `file_exists` | the reported file exists (accepts the workspace-relative or the absolute path) |
| `custom` | deferred to the vision model; reported as `skipped` |

## Tools

### 1. Document

| Tool | Title | Destructive | Confirmation | Input | Description |
| --- | --- | --- | --- | --- | --- |
| `photoshop.get_document` | Get Document | — | — | no arguments | Return the complete current state of a document: metadata (id, name, width, height, resolution, colorMode, layerCount) AND the full flat layer list including nested group children with parentId. Call this FIRST whenever you need to know what actually exists before planning anything. |
| `photoshop.create_document` | Create Document | — | — | 6 props, all optional | Create a new empty document and make it active. Use this when the request is to start something rather than change what is open — otherwise work on the document the user already has, because opening a new one hides their work. `name` is best-effort: `Document.name` is a getter on this build, so Photoshop usually names the document itself and the result reports the real name either way. Use `duplicate_document` when the name has to stick. |
| `photoshop.get_documents` | Get Documents | — | — | no arguments | List the open documents and which one is active. Cheap: it reads no layer data, so it is the right first call when deciding what to work on. |
| `photoshop.close_document` | Close Document | **yes** | **required** | 2 props, all optional | Close a document. With `save: false` (the default) unsaved changes are discarded, which is destructive; with `save: true` the document is saved to its current path first. |
| `photoshop.get_capabilities` | Get Capabilities | — | — | no arguments | Report which Photoshop features this build actually supports. Non-destructive: it inspects the API surface and the plugin's own record of what it has verified, and never touches the document. Call it before planning work that depends on masks, adjustments, selections or smart objects, so an unsupported feature can be refused up front rather than failing halfway through. |
| `photoshop.get_document_info` | Get Document Info | — | — | no arguments | Return only document metadata (id, name, width, height, resolution, colorMode, layerCount). Cheaper than get_document because it skips the layer walk. Use when you only need canvas geometry. |
| `photoshop.duplicate_document` | Duplicate Document | — | — | 2 props, all optional | Duplicate the target document. The copy becomes the active document and all following operations apply to it. Use this to safely derive a variant (for example a square version) without touching the original. |
| `photoshop.save_document` | Save Document | **yes** | **required** | 4 props, all optional | Save the document as PSD. Without `path` it saves in place, which OVERWRITES the original file — prefer `path` for anything AI-generated. |
| `photoshop.sample_color` | Sample Colour | — | — | 4 props, 2 required | Read the colour at a point in the document. The way to pick up a brand colour from an existing asset without guessing it. `radius` averages over a square, which is what you want for a gradient or a photo. |
| `photoshop.flatten_document` | Flatten Document | **yes** | **required** | 1 prop, all optional | Merge every visible layer into one, discarding hidden layers. Irreversible, and the single most destructive thing in this tool surface. |
| `photoshop.merge_visible_layers` | Merge Visible Layers | **yes** | **required** | 1 prop, all optional | Merge the visible layers into one, keeping hidden layers. Irreversible. |
| `photoshop.convert_color_mode` | Convert Colour Mode | **yes** | **required** | 2 props, 1 required | Convert the document between RGB, CMYK, Gray and Lab. Irreversible from the user's point of view once saved, and it changes every colour in the document — a conversion to CMYK will visibly shift a web palette. |

### 4. Images

| Tool | Title | Destructive | Confirmation | Input | Description |
| --- | --- | --- | --- | --- | --- |
| `photoshop.apply_image` | Apply Image Onto Layer | **yes** | **required** | 7 props, 1 required | Composite the contents of another **open** document onto a layer, with an optional offset, scale, blend mode and opacity. This replaces the layer's pixels rather than painting on top, which is why it asks for confirmation. The source must already be open: use `duplicate_document` or open it in Photoshop first. |
| `photoshop.list_brushes` | List Brushes | — | — | 1 prop, all optional | Report which brushes the running Photoshop exposes. Returns `available: false` with an empty list and a reason on every current UXP host, because the brush engine is not reachable from a plugin. Do not treat an empty list as a fault, and do not pick a brush name from it: `brushName` cannot change a stroke. |
| `photoshop.stroke_path` | Stroke Path | — | — | 10 props, 1 required | Draw a stroke along a path. | `photoshop.paint_stroke` | Paint Stroke | — | — | 10 props, 1 required | Draw a freehand stroke through a list of points. `smoothing` (0-100) applies corner-cutting passes to round off the polyline before it is drawn — raise it for a shaky mouse path, keep it at 0 for deliberate straight segments. | `photoshop.paint_gradient` | Paint Gradient | — | — | 13 props, 1 required | Fill with a colour ramp. `stops` are position/colour pairs along 0-100; two are enough for a straight fade, three or more for sky, water or any light that changes as it travels. `type: "linear"` runs along `direction` ("topToBottom" is the usual choice for a sky, darkening towards the horizon); `type: "radial"` fades outward from `center` and is what makes a glow around the sun or moon. The ramp is resolved into `bands` flat bands — raise it for a smoother result and lower it when a fill must be quick — and `smoothRadius` blurs the seams afterwards. | `photoshop.place_image` | Place Image | — | — | 4 props, 1 required | Place an external image file as a new layer. `path` must live inside the configured workspace. `fit` scales the placed layer; omit it to keep the native pixel size. |
| `photoshop.resize_layer` | Resize Layer | — | — | 7 props, all optional | Scale a layer to an absolute width/height, or by a ratio when `scale` is given. Smart objects resize without quality loss; raster layers are resampled with `resample`. |
| `photoshop.apply_filter` | Apply Filter | **yes** | **required** | no arguments | Apply a filter to a layer, destructively. ## Notes on specific tools

- `photoshop.get_document` returns metadata **and** the full flat layer list, so one
  round trip grounds the planner. `photoshop.get_document_info` skips the layer walk
  when only canvas geometry is needed.
- `photoshop.move_layer` accepts either `x`/`y` (absolute) or `dx`/`dy` (relative),
  never both.
- `photoshop.resize_canvas` changes the canvas **without scaling content**, matching
  Photoshop. Plans that need the artwork rescaled must include `resize_layer` /
  `set_text_font_size` steps.
- `photoshop.resize_layer` scales a text box but not its glyphs. Use
  `photoshop.set_text_font_size` for type.
- `photoshop.place_image` places a file as a smart object. The path must be inside the
  workspace; `fit` optionally scales the placed layer.
- `photoshop.export_document` dispatches on `format`; the three specific tools are
  thin, well-described aliases that a model picks more reliably.
- `photoshop.render_preview` returns a base64 PNG for the Studio preview pane. It
  writes to a temporary folder, never the workspace, and never mutates the document.

## Verification with `MCP Inspector`

```bash
npm run inspector
```

Use `http://127.0.0.1:3001/mcp` for a direct connection, or `http://localhost:3000/mcp`
to go through the Studio dev proxy (same origin, no CORS). With `MOCK_PHOTOSHOP=true`
this is a complete, safe playground for exercising every tool.
